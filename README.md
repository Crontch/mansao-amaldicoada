# 🏰 A Mansão: O Tabuleiro Amaldiçoado

Uma versão refatorada e aprimorada do jogo de tabuleiro digital "A Mansão". Este projeto transforma um arquivo HTML único em uma aplicação web modular, com melhorias visuais, lógica de jogo aprimorada e uma estrutura de código profissional.

## ✨ Melhorias Implementadas

- **Arquitetura Modular**: Separação de responsabilidades em arquivos CSS e JS (Config, Renderer, Logic, UI).
- **Interface Aprimorada**: Design mais sombrio e imersivo com animações de fade-in e efeitos de aura para o fantasma.
- **Lógica de IA**: O fantasma agora persegue o jogador mais próximo de forma inteligente, em vez de focar apenas no primeiro jogador.
- **Sistema de Níveis**: Adição de progressão de níveis ao coletar todas as relíquias.
- **Minigame de Dados**: Animação visual na rolagem do dado D20 para maior tensão.
- **Responsividade**: Melhor suporte para diferentes tamanhos de tela dentro do container do jogo.

## 🛠️ Tecnologias Utilizadas

- HTML5 (Canvas API)
- CSS3 (Flexbox, Grid, Animations)
- JavaScript Vanilla (ES6+)

## 🚀 Como Jogar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Crontch/mansao-amaldicoada.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Escolha o número de jogadores e tente coletar as 3 relíquias escondidas nos baús antes que o fantasma pegue seu grupo!
